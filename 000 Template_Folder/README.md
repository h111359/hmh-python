
# Project Environment Setup

This project contains all the necessary files to quickly set up a virtual environment and start working with data using Jupyter Notebook.

## How to Use

1. Copy the entire folder to your project directory.
2. Run `start_environment.cmd` to set up the virtual environment and start Jupyter Notebook.

## Requirements

- Python (latest version installed)
- CMD shell

## Notes

- The `start_environment.cmd` can be executed again after a system restart without deleting any work done up to that point.
